## 1. What We Collect

### 1.1 Claims You Submit
When you use VeritySwarm to verify a claim, we process the text of that claim to deliver your Verity Report. Claims may be stored temporarily (up to 30 days) for report retrieval. We do **not** associate submitted claims with your identity unless you have an authenticated account.

### 1.2 Account Information
If you create a Pro or Enterprise account:
- Email address (required)
- Payment information (processed by Stripe — we never store card numbers)
- Usage statistics (verification count, API call volume)

### 1.3 Technical Data
- IP address (for rate limiting and security)
- Browser/device type and OS (for performance optimization)
- Session identifiers
- Timestamps of API calls

### 1.4 Email Waitlist
If you join the waitlist, we store your email address solely for launch communications. You can unsubscribe at any time.

## 2. How We Use Your Data

| Data Type | Purpose |
|-----------|---------|
| Submitted claims | Deliver Verity Report; temporary storage for retrieval |
| Email | Account authentication; product updates; waitlist |
| Payment info | Processed by Stripe; we receive only transaction status |
| IP / technical | Rate limiting; fraud prevention; analytics |
| Anonymized claim patterns | Improving AI model accuracy (no PII attached) |

We do **not**:
- Sell your data to third parties
- Use submitted claims to train public AI models without anonymization
- Share personal data with advertisers

---

## 3. Data Sharing

We share data only with:

**Stripe** — payment processing. Stripe's privacy policy applies to payment data.
**Anthropic / xAI / Google** — AI inference providers process claims transiently to generate reports. These providers are bound by their own data handling policies. Claims are sent as API requests and are not retained by us beyond temporary report storage.
**Infrastructure providers** — Cloudflare (CDN, tunnel), hosting provider (server operations only).

We may disclose data if required by law, subpoena, or to protect against fraud or security threats.

## 4. GDPR Rights (EU/UK Users)

If you are in the EU or UK, you have the right to:
- **Access** — request a copy of your personal data
- **Rectification** — correct inaccurate data
- **Erasure** — request deletion ("right to be forgotten")
- **Portability** — receive your data in a machine-readable format
- **Object** — object to processing for legitimate interests
- **Restriction** — request we limit processing

To exercise any right, email privacy@verityswarm.com. We will respond within 30 days.

---

## 5. CCPA Rights (California Users)

California residents have the right to:
- Know what personal information we collect and how we use it
- Request deletion of personal information
- Opt out of the sale of personal information (we do not sell data)
- Non-discrimination for exercising privacy rights

## 7. Security

We implement industry-standard security measures including:
- HTTPS/TLS encryption in transit
- Encrypted storage for sensitive data
- API key authentication for account access
- Cloudflare WAF and DDoS protection

No system is perfectly secure. We will notify affected users of any material data breach within 72 hours of discovery.

## 8. Cookies

We use minimal, functional cookies only:
- Session authentication cookie (Pro accounts)
- Cloudflare security cookie

We do **not** use tracking or advertising cookies. No third-party analytics scripts.
